# UI Engineering

Use the project's existing design system before creating new visual patterns.

## Priorities

1. Usability
2. Clarity
3. Consistency
4. Accessibility
5. Performance
6. Visual polish

## Design

Follow:

- Minimal productivity UI
- Premium SaaS polish
- Apple-inspired simplicity
- Strong typography
- Generous spacing
- Subtle borders
- Soft depth
- Restrained accent color

Avoid visual noise.

## Components

Prefer reusable components.

Before creating a new component:

- Look for an existing component.
- Extend the existing component when appropriate.
- Create a new component only when the behavior or visual responsibility is genuinely different.

## States

Every interactive component should consider:

- Default
- Pressed
- Disabled
- Loading
- Error
- Empty
- Success

## Responsive Behavior

Design for small phones first.

Layouts must adapt naturally to larger phones and tablets.

Avoid hardcoded dimensions.

## Accessibility

Ensure:

- Adequate touch targets
- Meaningful labels
- Good contrast
- Readable typography
- Clear status feedback

## Final Principle

Do not optimize for visual complexity.

Optimize for a product that feels calm, premium and extremely easy to use.
